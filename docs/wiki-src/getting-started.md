# Getting started

Novyra is an Arch-based desktop built around Hyprland, with thoughtful defaults and CachyOS repositories for faster apps.

## First steps

- Explore the configured keyboard shortcuts.
- Update your packages.
- Read the installation guide for a fresh setup.

More guides will be added as Novyra grows.
